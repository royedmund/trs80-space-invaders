# Space Invaders — Roland SC-55 edition (Model III)

This separate edition retains Tim Walter / TechPrototyper's game engine and original credits. All audio is routed to the Roland SC-55 Sound Canvas, via the Model III's RS-232 port and the existing Arduino Nano fast v0.3 bridge. There is no cassette audio routine or fallback.

## Sound design

| Channel | GM program (zero-based) | Purpose | Notes / effects |
| --- | --- | --- | --- |
| 1 | 38 Synth Bass 1 | Four-note march | G2 F2 Eb2 C2; centre; light reverb |
| 2 | 81 Saw Lead | Player shot | E6; left of centre; reverb and chorus |
| 3 | 80 Square Lead | UFO chirp | G4/A4; right of centre; reverb and chorus |
| 4 | 127 Gunshot | Player death | C2; centre; reverb |
| 10 | Standard percussion kit | Invader and UFO explosions | Crash cymbal (49); centre; reverb |

The existing formation accumulator drives the march, including its approximately 14-fold relative acceleration. Separate frame-gated slots allow music and SFX to overlap. Each new event releases the previous note on its own slot; MIDI note-on with zero velocity releases notes. The SC-55 applies its own patch envelopes and reverb tails. A GM System On message is sent on starting a game, then program changes and volume/pan/reverb/chorus controllers configure the five used channels. This changes the module's current MIDI setup. BREAK and game over send note releases and cleanup controllers (64, 123, 120) on all five channels. If serial ready times out, new audio is disabled rather than using cassette. A disconnected link cannot be detected and a failed cleanup may require resetting the module.

## Build and play

```sh
zmac space_invaders_sc55.asm
trs80gp -m3 zout/space_invaders_sc55.cmd
```

For real hardware, transfer the assembled CMD in binary mode to LDOS as e.g. INVSC55/CMD. Use the [existing interface wiring](hardware/README.md) and [Nano firmware](firmware/serial_to_midi_fast/serial_to_midi_fast.ino). Power-cycle the Nano if it was in timed mode or faulted, connect MIDI OUT to the SC-55 MIDI IN, then connect the SC-55 audio output to speakers/mixer. No cassette audio cable required. The game uses raw MIDI without timed transport tokens or deliberate buffering delay. SPACE starts, arrows move, SPACE fires, BREAK returns to splash; BREAK again exits to DOS.

## Verification status

Experimental source only. Static checks confirm the audio hooks are present, the old cassette audio routines and FFh output are absent, and the original EMT-10 source and binaries are unchanged. The SC-55 source still needs zmac assembly, emulator regression and physical playback. Sound choices and channel balance are starting points, not measured or auditioned on a physical SC-55. Test simultaneous firing and march, UFO chirps, both explosion types, death, fast last-invader pacing, wave transitions and BREAK cleanup. Test the no-serial timeout path and verify there is no cassette audio. Existing gameplay wall-clock timing may change because cassette busy waits have been removed. The existing prebuilt CMD and disk are not SC-55 builds.
